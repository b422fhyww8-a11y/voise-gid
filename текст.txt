# Голосовой помощник по историческим местам

Индивидуальный проект. Веб-приложение, которое определяет положение пользователя,
находит исторические места Санкт-Петербурга рядом и озвучивает их название,
сторону (справа/слева/впереди) и краткую историческую справку.

## Цель
Создать прототип голосового гида, помогающего туристу ориентироваться
и узнавать историю мест без экскурсовода.

## Задачи
1. Изучить возможности веб-карт и геолокации в браузере.
2. Реализовать определение стороны объекта по компасу и азимуту.
3. Подключить синтез речи (Web Speech API).
4. Подготовить базу из 12 исторических мест с описаниями.
5. Протестировать на смартфоне.

## Технологии
HTML, CSS, JavaScript, Leaflet + OpenStreetMap, Web Speech API,
DeviceOrientation API, Geolocation API.

## Запуск
Открыть index.html через HTTPS (например, GitHub Pages),
разрешить геолокацию и компас, нажать «Старт».

## Ограничения
- компас недоступен на ПК;
- для iOS нужен HTTPS и разрешение пользователя;
- описания хранятся локально в data.js.
